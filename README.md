### 2. Healthcare Cost Classification & Association Rule Mining — R

Analysis of healthcare data using classification and association rule mining techniques.

The project includes:

- Healthcare cost classification using a decision tree
- 70/30 training and testing split
- Confusion matrix and model evaluation
- Accuracy, precision and recall
- Association rule mining using the Apriori algorithm
- Support and confidence analysis
- Data visualisation
